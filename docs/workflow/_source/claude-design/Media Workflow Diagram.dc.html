04 · STORAGE — 저장소 분리 구조
Upload Temp Storage
업로드 파일 임시 저장 영역. TM 완료 후 정리.
Master Storage 🔒
원본 보관 영역. 웹 직접 접근 불가. 권한자만 다운로드.
Proxy Storage
영상·이미지·오디오 프록시. 웹 서비스와 직접 연결.
Thumbnail Storage
목록 화면 대표 이미지 저장 영역.
Catalog Storage
영상 구간별 미리보기 이미지 저장 영역.

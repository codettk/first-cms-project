1차 패치로 항목 1~10의 P0·P1·P2 수정이 각 문서에 전부 반영 완료되었고, 2차 정합성 검토에서 발견된 잔여 2건(DB Table Spec §3 요약표에 progresses·audit_logs·allowed_transitions 누락 / Worker Agent §6 Claim 트랜잭션 소유 주석 누락)도 반영 완료. 2차 검토 확인 사항: COMMON은 transcode_profiles 전용(contents·OpenAPI MediaType 미포함) ✓ · DOCUMENT_INGEST 선행 [MA] ✓ · StateMachine 내부 트랜잭션 제거 ✓ · variant_key unique 3종 4개 문서 일치 ✓ · priority/progresses 확정 표기 ✓ · audit.context/write 분리 ✓ · OpenAPI $ref 잔존 0건 ✓ · retry-batch 라우트 선순위 ✓. 잔여 미결: P3 media_texts 분리 검토 1건. 아래 표의 각 항목에 반영 상태를 병기했다.
